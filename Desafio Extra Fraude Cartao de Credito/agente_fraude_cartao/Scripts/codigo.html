CONCLUSÕES

Os dados do dataset apresentados são, nesta amostra, predominantemente numéricos (Time, V1–V28, Amount). A variável alvo Class é binária (0/1) e funciona como rótulo para tarefas de classificação. Nesta análise, destacaram-se os nomes das colunas, a natureza numérica dos atributos e a presença de uma etiqueta binária. Os gráficos demonstrados ilustram distribuições (Amount), relacionamento Time x Amount e um heatmap simplificado para as variáveis V1–V28 na amostra apresentada.
