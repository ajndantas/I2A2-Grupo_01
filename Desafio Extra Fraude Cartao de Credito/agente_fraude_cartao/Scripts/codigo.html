Análise de Tipos de Dados no Conjunto de Fraudes de Cartão de Crédito

Os dados consistem em transações de cartão de crédito, com colunas anonimizadas (V1 a V28), Time, Amount e Class.

Tipos de Dados por Coluna

Coluna Tipo de Dados Descrição
Time Numérico (Contínuo) Número de segundos desde a primeira transação.
V1 a V28 Numérico (Contínuo) Variáveis anonimizadas (features derivadas de PCA).
Amount Numérico (Contínuo) Valor da transação.
Class Categórico (Binário) 0 = Normal, 1 = Fraude.

Conclusões

Colunas numéricas: Time, V1 a V28, Amount (todas contínuas). Coluna categórica: Class (binária). Na amostra, predomina transações normais (Class=0), com Amounts variando de baixos valores diários a outliers altos.
