Análise de Tipos de Dados - Fraudes de Cartão de Crédito

Dados Utilizados

A análise foi realizada com base em um extrato de 90 transações do conjunto de dados de fraudes de cartão de crédito, conforme fornecido no contexto.

Tipos de Dados por Coluna

A seguir, a classificação de cada coluna do conjunto de dados como numérica ou categórica.

Nome da Coluna Tipo de Dado Descrição
Time Numérico (Contínuo) Segundos decorridos desde a primeira transação.
V1 - V28 Numérico (Contínuo) Variáveis anônimas (resultantes de PCA).
Amount Numérico (Contínuo) Valor da transação.
Class Categórico (Binário) Indica se a transação é fraudulenta (1) ou não (0).

Conclusões

A análise do conjunto de dados de fraudes de cartão de crédito revela a seguinte classificação dos tipos de dados:

  • Colunas Numéricas: A grande maioria das colunas, incluindo Time, Amount, e todas as variáveis de V1 a V28, são numéricas. Elas representam quantidades mensuráveis, como tempo e valor monetário, ou componentes principais que são contínuos por natureza.
  • Coluna Categórica: A coluna Class é a única variável categórica. Ela é binária, representando duas categorias distintas: '0' para transações normais e '1' para transações fraudulentas.

Essa distinção é fundamental para a modelagem de detecção de fraudes, onde a variável `Class` serve como o alvo (target) a ser previsto, e as variáveis numéricas atuam como preditores (features).
