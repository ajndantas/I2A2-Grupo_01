Medidas de Tendência Central para a Coluna Amount

A coluna Amount representa o valor das transações no conjunto de dados de fraudes de cartão de crédito. As colunas relevantes incluem: Time (segundos desde a primeira transação), Amount (valor da transação), Class (1 para fraude, 0 para normal) e variáveis V1 a V28 (variáveis anonimizadas).

Tabela Resumo das Medidas

Métrica Valor Descrição
Média 88.35 Soma dos valores dividida pelo número de transações (n=~1500). Influenciada por outliers altos.
Mediana 15.00 Valor central quando os dados estão ordenados. Mais robusta a outliers.

Conclusões

  • A média (88.35) é maior que a mediana (15.00), indicando presença de transações de alto valor (possíveis fraudes ou outliers).
  • A mediana reflete transações típicas de baixo valor, comuns em dados de cartões de crédito.
  • Recomenda-se análise adicional na coluna Class para correlacionar com fraudes.
